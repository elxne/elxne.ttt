# Contrat elxne.ttt

Page de contrat de réservation et d'acompte pour les rendez-vous tatouage de elxne.ttt.

- **Espace tatoueuse** : préparer un rendez-vous et envoyer le lien du contrat au client (accès par code).
- **Client** : ouvre le lien reçu, complète ses informations, accepte les conditions et signe.
- Le contrat signé (PDF) est envoyé automatiquement par e-mail à la tatoueuse, avec une copie au client.

## Modifier les réglages
Dans `index.html`, bloc `CONFIG` : e-mail de réception, nom légal, SIRET, adresse et code d'accès.

Envoi des e-mails via [FormSubmit](https://formsubmit.co).
